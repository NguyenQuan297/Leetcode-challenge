# 389. Find the Difference

**Topic:** [Sorting](../) · **Difficulty:** Easy

## Description

You are given two strings `s` and `t`.

String `t` is generated by random shuffling string `s` and then adding **one** more letter at a random position.

Return the letter that was added to `t`.

## Examples

**Example 1:**

- Input: `s = "abcd"`, `t = "abcde"`
- Output: `"e"`

**Example 2:**

- Input: `s = ""`, `t = "y"`
- Output: `"y"`

## Constraints

- `0 <= s.length <= 1000`
- `t.length == s.length + 1`
- `s` and `t` consist of lowercase English letters.

## Approach

XOR of character codes: every letter from `s` appears twice (once in `s`, once in `t`), except the added letter appears only in `t`.
